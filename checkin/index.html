원신 리딤 자동출첵

방송 리딤코드도, 매일 출석도 알아서 챙겨요. 한 번 로그인해 두면 끝이에요.

지금은 플레이스토어 비공개 테스트 중이에요 정식 출시 전이라 아래 순서대로 해야 설치할 수 있어요. 1번을 건너뛰면 2·3번이 열리지 않아요.
  1. 테스터 그룹 가입구글 계정으로 '그룹 가입'을 눌러 주세요.
    그룹 가입
  2. 테스터 등록'테스터 되기'를 눌러 주세요.
    테스터 되기
  3. 설치하고 로그인앱에서 호요랩에 로그인하면 매일 알아서 돌아가요.
    설치하기

안드로이드 8.0 이상. 정식 출시를 위해 테스터가 2주 동안 앱을 유지해야 해요. 지우지 말아 주세요. 불편한 점은 apps@sumi.kr로 알려 주시면 고쳐서 올릴게요.

하는 일

  • 리딤코드 자동 입력 방송·이벤트로 공개된 코드를 찾아 고른 서버·캐릭터로 입력해요. 원석은 게임 우편함으로 와요.
  • 새벽 1시 자동 출석 폰 시계가 아니라 호요랩 서버 시각에 맞춰, 날짜가 바뀐 직후에 출석해요.
  • 보상 내역 이번 달 받은 원석·모라와 리딤 코드로 받은 보상의 합계를 한눈에 봐요.
  • 보충 출석 놓친 날이 있으면 알려 주고, 누르면 바로 보충해요.
  • 여러 계정, 알림 골라 받기 계정을 여러 개 등록할 수 있고, 알림을 골라 받으며 밤에는 소리 없이 알려요.

안심하고 쓰세요

  • 로그인은 앱 안에서 호요랩 공식 로그인 페이지로 직접 해요.
  • 아이디·비밀번호는 저장하지 않고, 로그인 정보는 폰 안에만 있어요.
  • 개발자 서버가 없고, 광고·분석 도구도 없어요.
  • 앱 크기 1MB 미만. 앱을 열지 않아도 알아서 돌고, 하루에 몇 번 호요랩과 짧게 통신할 뿐이라 배터리·데이터 부담이 거의 없어요.
  • 소스 코드를 모두 공개해 두었어요: GitHub
