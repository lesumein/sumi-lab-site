SUMI LAB · 원신 코드·픽업

개인정보처리방침

로그인하지 않고, 알림을 켠 경우에만 알림에 필요한 정보가 알림 서비스에 저장됩니다.

이 문서는 Sumi Lab이 만든 웹앱 "원신 코드·픽업"(https://apps.sumi.kr/genshin-codes/, 이하 "웹앱")이 어떤 정보를 다루는지 설명합니다. 안드로이드 앱 "원신 리딤 자동출첵"은 별도의 방침을 따릅니다.

웹앱은 HoYoverse(COGNOSPHERE)와 관계없는 비공식 도구입니다.

알림을 켜지 않은 경우

  • 웹앱은 로그인하지 않으며 이름, 이메일, 게임 계정 같은 정보를 받지 않습니다.
  • '입력' 버튼으로 열어 본 코드 표시와 알림을 켰는지 여부만 이 기기의 브라우저 저장소에 저장합니다. 브라우저의 사이트 데이터를 지우면 함께 지워집니다.
  • 리딤 코드·픽업·이벤트 자료는 이 사이트(apps.sumi.kr, GitHub Pages)에서 받고, 이벤트 배너와 복각표의 캐릭터 얼굴 그림은 HoYoLAB(호요버스) 서버에서 받습니다. 일반 웹 요청처럼 접속 기록(IP 등)은 GitHub과 HoYoLAB이 처리합니다.
  • 알림을 켜기 전에는 알림 서비스(OneSignal)의 스크립트를 불러오지 않습니다.

알림을 켠 경우

'알림 받기'를 누르고 브라우저 알림을 허용하면, 새 리딤 코드 알림을 보내기 위해 아래 정보가 알림 서비스 OneSignal에 저장됩니다.

  • 항목: 브라우저 푸시 구독 정보(알림을 받을 주소와 암호화 키), 브라우저·기기 종류, 언어, 시간대, 접속 IP, 구독한 날과 마지막 접속일, 알림 수신·클릭 기록
  • 목적: 새 리딤 코드 알림 발송. 광고나 다른 목적으로 쓰지 않습니다.
  • 보관 기간: 알림을 끄거나 브라우저에서 알림 권한·사이트 데이터를 지울 때까지. 그 뒤 OneSignal의 보관 정책에 따라 지워집니다.

개인정보의 국외 이전

  • 이전받는 자: OneSignal, Inc.(미국, 개인정보처리방침)
  • 이전되는 국가: 미국
  • 이전 항목: 위 '알림을 켠 경우'의 항목
  • 이전 목적: 새 리딤 코드 웹 푸시 알림 발송
  • 이전 시기와 방법: 알림을 켤 때와 알림을 받을 때, 네트워크를 통해 전송
  • 보유 기간: 알림을 끌 때까지
  • 거부 방법과 영향: 알림을 켜지 않으면 아무 정보도 이전되지 않으며, 알림을 받지 못하는 것 말고는 웹앱의 다른 기능은 그대로 쓸 수 있습니다. 이미 켰다면 웹앱의 '알림 끄기'나 브라우저 설정에서 끌 수 있습니다.
